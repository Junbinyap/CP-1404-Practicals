# Practical 07

## Overview
This repository contains my CP1404 practicals, where I practice Python programming concepts, including object-oriented programming, file handling, and clean code principles.

## Lessons Learned About Clean Code
- Single Responsibility Principle (SRP): Each function/class should focus on a single task to improve maintainability.
- Avoid Magic Numbers and Strings: Using named constants instead of hardcoded values makes code clearer and easier to modify.
- Consistent Naming and Formatting: Following PEP 8 conventions improves readability and collaboration.
